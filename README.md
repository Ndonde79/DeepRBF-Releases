# DeepRBF

DeepRBF geological modelling and geostatistical workflow publications.

## Technical case studies

### Geological Architecture of the Thalanga Host Horizon

[A Section-Based Interpretation and Validation Study Using DeepRBF](case-studies/thalanga/README.md)

A local geological modelling study documenting explicit section controls, paired boundaries, block assignment and withheld-hole validation. The article reports both demonstrated capabilities and unresolved OH continuity. It is not a Mineral Resource estimate or a claim of production readiness.

The case-study directory includes aggregate validation metrics and a comparison chart. Raw drilling data and coordinate-bearing model files are not included.

## Release scope

The current publication is technical documentation. It does not publish a new engine binary, installer or software version. Public availability of this repository does not confer redistribution rights over third-party source data.
